# Invitation card maker

A single-file wedding invitation card maker. Open `index.html` in a web browser (works offline on phones and computers), type a guest's name and how many people the card admits, then save the card as a PDF or picture, or share it.

- The file ships with placeholder wording (dummy names, venue, date and contacts) and a simple placeholder card background drawn in code.
- "Edit card wording" changes the text on cards saved in that session; edits are not kept after the page is refreshed.
- jsPDF 2.5.1 and the Alex Brush and Belleza fonts are embedded, so no network access is needed.
